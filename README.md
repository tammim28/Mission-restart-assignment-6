# undefined
 যখন কোনো ভেরিয়েবল declare করা হয় কিন্তু কোনো value দেওয়া হয় না, তখন সেটি undefined থাকে।

# null
 ইচ্ছা করে কোনো ভেরিয়েবলকে খালি বা empty দেখাতে null ব্যবহার করা হয়।

# map()
Array এর প্রতিটি element নিয়ে কাজ করে নতুন একটি array return করে

# forEach()
শুধু array loop করে, কোনো নতুন array return করে না

# == (Loose Equality)
শুধু value compare করে, type check করে না

# === (Strict Equality)
value এবং type দুটোই compare করে

# API fetch করার ক্ষেত্রে async/await এর গুরুত্ব
async/await ব্যবহার করলে asynchronous code সহজ ও readable হয়। try/catch দিয়ে error handle করা সহজ হয়

# JavaScript এ Scope কী?
Scope মানে হলো কোনো ভেরিয়েবল কোথায় ব্যবহার করা যাবে।

## Global Scope
পুরো প্রোগ্রাম জুড়ে ব্যবহার করা যায়।

## Function Scope
শুধু function এর ভিতরে ব্যবহার করা যায়।

## Block Scope
শুধু {} ব্লকের ভিতরে ব্যবহার করা যায় (let এবং const এর ক্ষেত্রে)।
